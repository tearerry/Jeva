# 나만의 미디어 라이브러리, 더 아름답게.

**Jeva**는 Jellyfin을 위한 독립적인 Windows 클라이언트입니다. 내 서버에 보관된 영화와 TV 프로그램을 OTT 서비스를 이용하듯 편리하고 세련된 화면에서 감상할 수 있습니다.

<p align="center"><img src="../../assets/screenshots/home.png" width="100%" alt="Jeva 홈 화면"></p>

## 주요 기능

- **내 취향대로 꾸미는 홈:** 홈에 표시할 라이브러리를 선택하고, 콘텐츠 섹션의 표시 여부와 순서를 변경할 수 있습니다.
- **OTT 스타일 인터페이스:** 영화와 TV 프로그램을 풍부한 아트워크와 상세 정보로 둘러볼 수 있습니다.
- **다양한 화면 설정:** 테마, 대표 콘텐츠 레이아웃, 카드 표시 방식을 변경할 수 있습니다.
- **편리한 탐색:** 라이브러리별 탐색, 검색, 필터 및 정렬 기능을 제공합니다.
- **더 폭넓은 콘텐츠 지원:** 뮤직비디오와 로컬 부가 영상(Local Extras)을 지원합니다.
- **15개 언어:** 다양한 언어로 이용할 수 있으며, 국가별 연령 등급 표시도 지원합니다.

## 시작하기

1. [Releases](https://github.com/tearerry/Jeva/releases)에서 최신 Windows 설치 파일을 다운로드합니다.
2. Jeva를 설치하고 실행합니다.
3. Jellyfin 서버에 연결하면 바로 사용할 수 있습니다.

**지원 플랫폼:** Windows x64

## 개발자 모드

Jeva에는 메타데이터 새로고침과 콘텐츠 정보 편집을 위한 개발자 모드가 숨겨져 있습니다.

**설정 → 정보(About)**에서 **Jeva 아이콘을 여러 번 클릭**하면 개발자 모드를 활성화할 수 있습니다.

## 의견 및 오류 제보

문제를 발견했거나 제안할 기능이 있다면 [GitHub Issues](https://github.com/tearerry/Jeva/issues)에 남겨주세요.

<sub>**안내:** Jeva는 독립적인 프로젝트이며, Jellyfin 프로젝트와 제휴 관계가 없고 공식적인 승인이나 보증을 받지 않았습니다.</sub>
