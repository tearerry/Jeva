## 세심한 부분까지

- **첫 장면부터 자막**<br>파일에서 바로 읽어 와서, 어디로 건너뛰어도 바로 나옵니다.
- **내 언어, 내 지역 등급**<br>15개 언어를 지원하고, 연령 등급은 사는 나라의 방식대로 보여 줍니다.
- **홈은 내 마음대로**<br>홈에 보일 라이브러리를 고르고, 라이브러리마다 탭을 따로 둘 수 있습니다.
- **스포일러 방지**<br>아직 보지 않은 에피소드의 줄거리를 라이브러리별로 흐리게 가립니다.
- **부가 영상과 사진**<br>작품 화면에서 예고편과 메이킹 영상을, 사진 앨범은 전체 화면으로.
- **보던 곳에서 그대로**<br>시청 중인 콘텐츠와 다음 에피소드가 서버와 항상 맞춰집니다.

## 시작하기

Windows 10 또는 11(x64)과 Jellyfin, Plex, Emby 중 하나의 서버가 필요합니다.

1. <a href="https://github.com/tearerry/Jeva/releases/latest">최신 릴리스</a>에서 Jeva를 다운로드하세요.
2. 앱을 열고 서버를 고르세요. 같은 네트워크의 서버는 자동으로 나타납니다.
3. 로그인하고 감상을 시작하세요.

설치 없이 쓰고 싶다면 포터블 ZIP을 받으세요. 어느 폴더에서든 실행되고, 데이터는 바로 옆에 보관됩니다.

## 개발자 모드

메타데이터와 이미지를 편집하거나 라이브러리를 스캔하는 기능을 앱 안에서 쓸 수 있습니다. <strong>설정 → 정보</strong>에서 Jeva 아이콘을 연속으로 7번 클릭하면 켜집니다.
