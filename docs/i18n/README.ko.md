Jeva는 Jellyfin, Plex, Emby를 지원하는 Windows용 미디어 클라이언트입니다.

<p>
  <img src="../../assets/screenshots/home-crime-101.ac6684badb2a.png" width="100%" alt="Jeva — Crime 101 home screen">
</p>

### 작품 정보

줄거리와 아트워크, 출연진을 한눈에 살펴보세요. 보던 작품은 멈춘 곳에서 바로 이어 볼 수 있습니다.

### 화면 설정

좋아하는 테마를 고르고 홈 화면의 섹션과 순서를 바꿔보세요. 15개 언어를 지원하며, 연령 등급도 지역에 맞게 표시합니다.

## 감상 시작하기

**Windows x64**와 연결할 **Jellyfin, Plex 또는 Emby 서버**가 필요합니다.

1. [최신 릴리스](https://github.com/tearerry/Jeva/releases/latest)에서 설치 파일을 다운로드하세요.
2. Jeva를 설치하고 실행하세요.
3. 사용하는 서버에 연결하고 로그인하세요.
