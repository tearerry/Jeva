# Ваша медиатека. Красота в каждой детали.

**Jeva** — независимый клиент Jellyfin для Windows. Смотрите фильмы и сериалы со своего сервера в элегантном интерфейсе, вдохновлённом современными стриминговыми сервисами.

<p align="center"><img src="../../assets/screenshots/home.png" width="100%" alt="Главный экран Jeva"></p>

## Возможности

- **Главная страница под вас:** Выбирайте отображаемые библиотеки, настраивайте разделы и их порядок.
- **Кинематографичный интерфейс:** Открывайте фильмы и сериалы с обложками и подробными описаниями.
- **Гибкое оформление:** Меняйте темы, варианты главного баннера и стили карточек.
- **Удобный поиск:** Просматривайте библиотеки, ищите, фильтруйте и сортируйте контент.
- **Больше видео:** Поддержка музыкальных клипов и локальных дополнительных материалов.
- **15 языков:** Многоязычный интерфейс и возрастные рейтинги с учётом региона.

## Начало работы

1. Скачайте последнюю версию установщика Windows в разделе [Releases](https://github.com/tearerry/Jeva/releases).
2. Установите и запустите Jeva.
3. Подключитесь к своему серверу Jellyfin.

**Платформа:** Windows x64

## Режим разработчика

В Jeva есть скрытый режим разработчика для обновления метаданных и редактирования информации о медиаконтенте.

Чтобы включить его, откройте **Настройки → О программе (About)** и **несколько раз нажмите на значок Jeva**.
