## Dan detailnya

- **Subtitle sejak bingkai pertama**<br>Dibaca langsung dari file dan langsung muncul, ke mana pun Anda melompat.
- **Bahasa dan rating usia Anda**<br>15 bahasa, dengan rating usia ditampilkan sesuai sistem di negara Anda.
- **Beranda sesuka Anda**<br>Pilih koleksi yang muncul di Beranda dan beri tiap koleksi tab sendiri.
- **Perlindungan spoiler**<br>Kaburkan sinopsis episode yang belum Anda tonton, per koleksi.
- **Ekstra dan foto**<br>Trailer dan di balik layar di setiap judul, album foto dalam layar penuh.
- **Lanjut dari terakhir kali**<br>Lanjutkan Menonton dan Episode Berikutnya, selalu sinkron dengan server Anda.

## Mulai

Anda memerlukan Windows 10 atau 11 (x64) dan server Jellyfin, Plex, atau Emby.

1. Unduh Jeva dari <a href="https://github.com/tearerry/Jeva/releases/latest">rilis terbaru</a>.
2. Buka aplikasinya dan pilih server Anda; server di jaringan Anda muncul dengan sendirinya.
3. Masuk, lalu mulai menonton.

Tidak ingin menginstal? ZIP portabel bisa dijalankan dari folder mana pun dan menyimpan datanya tepat di sebelahnya.

## Mode Pengembang

Edit metadata dan gambar, atau pindai koleksi Anda, langsung dari aplikasi. Untuk mengaktifkannya, buka <strong>Pengaturan → Tentang</strong> lalu klik ikon Jeva tujuh kali berturut-turut.
