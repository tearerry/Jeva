# Koleksi media Anda, tampil lebih memukau.

**Jeva** adalah klien Jellyfin independen untuk Windows. Nikmati film dan serial dari server pribadi Anda melalui antarmuka elegan yang terinspirasi layanan streaming modern.

<p align="center"><img src="../../assets/screenshots/home.png" width="100%" alt="Layar beranda Jeva"></p>

## Fitur utama

- **Beranda sesuai selera:** Pilih pustaka yang tampil, lalu atur bagian beranda dan urutannya.
- **Tampilan ala layanan streaming:** Jelajahi film dan serial melalui gambar serta halaman detail yang menarik.
- **Desain yang bisa disesuaikan:** Ganti tema, tata letak konten unggulan, dan gaya kartu.
- **Navigasi praktis:** Cari, filter, urutkan, dan jelajahi setiap pustaka media.
- **Lebih banyak jenis video:** Mendukung video musik dan konten ekstra lokal.
- **15 bahasa:** Antarmuka multibahasa dengan klasifikasi usia sesuai wilayah.

## Memulai

1. Unduh penginstal Windows terbaru dari [Releases](https://github.com/tearerry/Jeva/releases).
2. Instal dan jalankan Jeva.
3. Hubungkan ke server Jellyfin Anda.

**Platform:** Windows x64

## Mode Pengembang

Jeva menyediakan Mode Pengembang tersembunyi untuk menyegarkan metadata dan mengedit informasi media.

Untuk mengaktifkannya, buka **Pengaturan → Tentang (About)** lalu **klik ikon Jeva beberapa kali**.
