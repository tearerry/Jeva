Jeva 是一款支持 Jellyfin、Plex 和 Emby 的 Windows 媒体客户端。

<p>
  <img src="../../assets/screenshots/home-crime-101.ac6684badb2a.png" width="100%" alt="Jeva — Crime 101 home screen">
</p>

### 作品详情

剧情简介、海报和演员信息，一眼就能找到。还没看完的作品，也能随时接着看。

### 界面设置

选择主题，调整首页栏目和排列顺序。Jeva 支持 15 种语言，也会根据地区显示年龄分级。

## 开始观看

你需要 **Windows x64**，以及可连接的 **Jellyfin、Plex 或 Emby 服务器**。

1. 前往[最新版本](https://github.com/tearerry/Jeva/releases/latest)下载安装程序。
2. 安装并打开 Jeva。
3. 连接你使用的服务器并登录。

<details>
<summary>开发者模式</summary>

如果需要刷新元数据或编辑媒体信息，请打开**设置 → 关于（About）**，**连续点击 Jeva 图标 7 次**，即可开启开发者模式。

</details>
