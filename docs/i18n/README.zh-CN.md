## 细节之处

- **从第一帧开始的字幕**<br>直接从文件读取，无论跳到哪里都能立即显示。
- **你的语言，你的分级**<br>支持 15 种语言，年龄分级按你所在国家的方式显示。
- **首页由你决定**<br>选择哪些媒体库显示在首页，还可以为每个媒体库单独设置标签页。
- **防剧透**<br>按媒体库模糊尚未观看剧集的简介。
- **花絮与照片**<br>作品页面提供预告片和幕后花絮，相册可全屏浏览。
- **从上次的地方继续**<br>继续观看和下一集，始终与服务器同步。

## 开始使用

需要 Windows 10 或 11（x64），以及一台 Jellyfin、Plex 或 Emby 服务器。

1. 从<a href="https://github.com/tearerry/Jeva/releases/latest">最新版本</a>下载 Jeva。
2. 打开应用并选择服务器，同一网络中的服务器会自动出现。
3. 登录后即可开始观看。

不想安装？下载便携版 ZIP，可在任意文件夹中运行，数据就保存在它旁边。

## 开发者模式

可以直接在应用中编辑元数据和图片，或扫描媒体库。在<strong>设置 → 关于</strong>中连续点击 Jeva 图标七次即可开启。
