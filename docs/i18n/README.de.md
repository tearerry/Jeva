# Deine Mediathek. So schön wie nie.

**Jeva** ist ein unabhängiger Jellyfin-Client für Windows. Genieße Filme und Serien von deinem eigenen Server in einer eleganten Oberfläche, die an moderne Streamingdienste erinnert.

<p align="center"><img src="../../assets/screenshots/home.png" width="100%" alt="Jeva-Startseite"></p>

## Funktionen

- **Deine persönliche Startseite:** Wähle Bibliotheken aus und passe Bereiche und deren Reihenfolge an.
- **Kino-Atmosphäre:** Entdecke Filme und Serien mit großflächigen Bildern und detaillierten Informationen.
- **Individuelle Darstellung:** Ändere Designs, hervorgehobene Ansichten und Kachelstile.
- **Einfaches Stöbern:** Durchsuche, filtere und sortiere deine einzelnen Bibliotheken.
- **Mehr Videoinhalte:** Unterstützt Musikvideos und lokale Extras.
- **15 Sprachen:** Mehrsprachige Oberfläche mit regional passenden Altersfreigaben.

## Erste Schritte

1. Lade das aktuelle Windows-Installationsprogramm unter [Releases](https://github.com/tearerry/Jeva/releases) herunter.
2. Installiere und starte Jeva.
3. Verbinde die App mit deinem Jellyfin-Server.

**Plattform:** Windows x64

## Entwicklermodus

Jeva bietet einen versteckten Entwicklermodus zum Aktualisieren von Metadaten und Bearbeiten von Medieninformationen.

Öffne **Einstellungen → Über (About)** und **klicke mehrmals auf das Jeva-Symbol**, um ihn zu aktivieren.
