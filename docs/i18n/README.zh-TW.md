Jeva 是支援 Jellyfin、Plex 與 Emby 的 Windows 媒體用戶端。

<p>
  <img src="../../assets/screenshots/home-crime-101.ac6684badb2a.png" width="100%" alt="Jeva — Crime 101 home screen">
</p>

### 作品資訊

劇情簡介、海報與演員資訊，都在同一個畫面。還沒看完的作品，也能隨時接著看。

### 介面設定

挑選主題，調整首頁區塊與排列順序。Jeva 支援 15 種語言，也會依地區顯示年齡分級。

## 開始觀看

你需要 **Windows x64**，以及可連線的 **Jellyfin、Plex 或 Emby 伺服器**。

1. 到[最新版本](https://github.com/tearerry/Jeva/releases/latest)下載安裝程式。
2. 安裝並開啟 Jeva。
3. 連線至你使用的伺服器並登入。

<details>
<summary>開發者模式</summary>

若要重新整理中繼資料或編輯媒體資訊，請開啟**設定 → 關於（About）**，**連續點擊 Jeva 圖示 7 次**，即可啟用開發者模式。

</details>
