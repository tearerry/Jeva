## 喜歡的作品，好好看。

用 Windows 上的 Jeva，欣賞 Jellyfin 伺服器裡的電影與影集。逛逛自己的媒體庫，挑一部想看的，享受屬於你的觀影時光。

<p>
  <img src="../../assets/screenshots/home.png" width="100%" alt="Jeva — 喜歡的作品，好好看。">
</p>

### 從認識一部作品開始

劇情簡介、海報與演員資訊，都在同一個畫面。還沒看完的作品，也能隨時接著看。

<p>
  <img src="../../assets/screenshots/details.png" width="100%" alt="Jeva — 從認識一部作品開始">
</p>

### 換成你喜歡的樣子

挑選主題，調整首頁區塊與排列順序。Jeva 支援 15 種語言，也會依地區顯示年齡分級。

## 開始觀看

你需要 **Windows x64**，以及可連線的 **Jellyfin 伺服器**。

1. 到[最新版本](https://github.com/tearerry/Jeva/releases/latest)下載安裝程式。
2. 安裝並開啟 Jeva。
3. 連線至 Jellyfin 伺服器並登入。

<details>
<summary>開發者模式</summary>

若要重新整理中繼資料或編輯媒體資訊，請開啟**設定 → 關於（About）**，**連續點擊 Jeva 圖示 7 次**，即可啟用開發者模式。

</details>
